4 Database Schema

All 4 MongoDB collections with every field explained.

Collection: users

FieldTypeRequiredDescription
_idObjectIdAutoAuto-generated primary key by MongoDB
nameStringYesEmployee full name
emailStringYes, UniqueUnique email address (used as login identifier)
roleStringYesEnum: 'employee' or 'admin'
statusStringYesEnum: 'pending', 'approved', 'rejected'
dept_idObjectIdNoReference → departments._id
leave_balancesArrayAutoEmbedded array — one entry per leave type (see below)
createdAtDateAutoMongoose timestamps

Embedded: leave_balances[]

FieldTypeDescription
leave_type_idObjectIdReference → leave_types._id
leave_type_nameStringDenormalised name for fast display (avoids join)
total_daysNumberMax allowed paid days (copied from leave_type.max_paid_days)
used_daysNumberDays consumed. Incremented atomically on leave approval
remaining_daysNumbertotal_days − used_days. Decremented atomically on approval

Collection: departments

FieldTypeDescription
_idObjectIdPrimary key
dept_nameString, UniqueDepartment name (Engineering, HR, etc.)

Collection: leave_types

FieldTypeDescription
_idObjectIdPrimary key
nameString, UniqueLeave type name (e.g. Sick Leave)
max_paid_daysNumberMaximum paid days allowed per year for this type
color_codeStringHex colour used in UI cards and calendar dots
is_activeBooleanSoft-delete flag. False = deactivated, hidden from employees

Collection: leave_requests

FieldTypeDescription
_idObjectIdPrimary key
user_idObjectIdReference → users._id (the applicant)
type_idObjectIdReference → leave_types._id
leave_type_nameStringDenormalised name (avoids join on read)
start_dateDateLeave start date
end_dateDateLeave end date
total_daysNumberWorking days (Mon–Fri only, weekends excluded)
is_paidBooleanWhether leave is paid (true) or unpaid (false)
reasonStringEmployee's stated reason for leave
statusStringEnum: 'pending', 'approved', 'rejected'
priorityStringAuto-assigned: 'high' (Sick/Emergency), 'medium' (Casual), 'low' (others)
admin_commentStringAdmin's note when approving or rejecting
