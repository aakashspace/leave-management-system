1 Project Overview

Introduction, problem statement, and project objectives.

📌 Introduction

The Leave Management System (LMS) is a full-stack web application built to automate and streamline the process of applying for, approving, tracking, and managing employee leave within an organisation. Traditional paper-based or spreadsheet methods are error-prone, slow, and difficult to audit. This system replaces them with a centralised, digital platform accessible via any modern web browser.

The application is built on the M-E-V-N stack (MongoDB, Express.js, Vue.js, Node.js) and runs entirely on the local machine — no internet deployment needed for the college submission.

Problem Statement

Manual leave management systems suffer from the following problems:

❌ Before (Manual)

  • Paper/spreadsheet-based, prone to loss
  • No real-time visibility of leave balances
  • Inconsistent policy enforcement
  • Human errors in balance calculation
  • No priority-based handling of urgent leave
  • No reporting or analytics

✅ After (LMS)

  • Centralised digital database (MongoDB)
  • Live leave balance with progress bars
  • Configurable leave policies per type
  • Atomic balance deduction on approval
  • Auto-priority (High/Medium/Low)
  • Reports by type, department, employee
