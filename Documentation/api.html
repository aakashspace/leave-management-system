6 API Reference

All REST endpoints for the LMS backend.

Base URL: http://localhost:5000/api  ·  All responses: { success: true/false, data: ..., message: ... }

Users API

MethodEndpointDescriptionBody / Params
GET/usersGet all usersQuery: ?status= ?dept_id=
GET/users/pendingGet pending users only—
POST/usersRegister new username, email, role, dept_id
GET/users/:idGet user by ID—
PUT/users/:idUpdate user name/deptname, dept_id
PUT/users/:id/approveApprove user & init balances—
PUT/users/:id/rejectReject user—
DELETE/users/:idDelete user—

Leave Requests API

MethodEndpointDescriptionBody / Params
POST/leave-requestsSubmit leave applicationuser_id, type_id, start_date, end_date, is_paid, reason
GET/leave-requests/my/:user_idGet my leave history—
GET/leave-requests/allGet all requests (admin)Query: ?status= ?priority= ?user_id=
PUT/leave-requests/:id/statusApprove or reject requeststatus, admin_comment
PUT/leave-requests/:id/cancelEmployee cancels pending—

Reports API

MethodEndpointReturns
GET/reports/dashboardtotalUsers, pendingApprovals, totalLeaves, pendingLeaves, approvedLeaves, rejectedLeaves, highPriority
GET/reports/leave-statsbyType (count, totalDays per type), byStatus (count per status)
GET/reports/employee-statsname, totalRequests, totalDays, approved per employee
GET/reports/dept-statstotalRequests, totalDays, approved, pending, rejected per department

MethodEndpointDescription
