10 Future Scope

8 planned enhancements to extend the system beyond its current scope.

📧 Email Notifications

Integrate Nodemailer to send automated emails on leave submission, approval, and rejection. Reminder emails for pending approvals.

🏗 Multi-Level Approval

Add a Manager role. Leave requests first go to the Department Manager, then to Admin. Implement approval chain with escalation.

📅 Calendar Sync

Integration with Google Calendar / Outlook API to automatically block approved leave days in the employee's external calendar.

📱 Mobile App

Build a React Native or Flutter mobile app using the same Express.js backend API — no backend changes needed.

🎉 Holiday Management

Admin defines public holidays. System auto-excludes them from working-day calculations (currently only excludes weekends).

🔐 JWT Authentication

Add bcrypt password hashing and JWT tokens for production-level security. Currently simplified for local academic use.

📊 Chart.js Analytics

Replace CSS bar charts with Chart.js interactive charts — line graphs for trends, pie charts for type distribution.

🔄 Leave Accrual

Monthly automatic leave balance accrual (e.g., +1.25 days/month) instead of annual flat allocation. Cron job on the backend.
