3 System Architecture

Three-tier architecture, request-response flow, and complete folder structure.

Three-Tier Architecture

🎨 Tier 1 — Presentation Layer (Frontend · Port 5173)

  • Built with Vue.js 3 using Composition API (<script setup>)
  • Single Page Application — no full page reloads, instant navigation
  • 11 view pages: SelectUser, Register tab, 5 Employee views, 6 Admin views
  • State: Pinia store persisted to localStorage (current user session)
  • Routing: Vue Router with lazy-loaded components
  • HTTP: Axios with Vite proxy to backend (/api → localhost:5000)
  • Styling: Pure CSS with CSS variables — no external UI library (Bootstrap/Tailwind)

⚙️ Tier 2 — Application Layer (Backend · Port 5000)

  • Built with Node.js + Express.js
  • RESTful API — responds with JSON, stateless architecture
  • 5 route files: users, departments, leave-types, leave-requests, reports
  • 5 controller files containing all business logic
  • CORS enabled — allows requests from Vue dev server (port 5173)
  • Environment variables via .env (PORT, MONGO_URI)

🗄️ Tier 3 — Data Layer (MongoDB · Port 27017)

  • MongoDB Community Server running as Windows Service
  • 4 collections: users, departments, leave_types, leave_requests
  • Mongoose ODM for schema validation and query API
  • Database: lms_db
  • Leave balances embedded inside user documents for fast reads (denormalization)

Request-Response Flow

User Action → Vue Component → Axios HTTP → Express Route → Controller → Mongoose → MongoDB → JSON Response → UI Updates
