2 Technology Stack

All technologies used in the M-E-V-N stack and why this combination was chosen.

🍃

MongoDB

NoSQL document database. Stores data as JSON-like BSON documents. Flexible schema, ideal for embedded arrays (leave_balances inside users).

v8.x
⚡

Express.js

Minimal Node.js web framework. Handles routing, middleware, and RESTful API endpoints. Runs on port 5000.

v4.18.x
💚

Vue.js 3

Reactive, component-based frontend framework using Composition API. Provides live UI updates without full page reloads (SPA).

v3.3.x
🟢

Node.js

JavaScript server-side runtime. Non-blocking I/O handles concurrent API requests efficiently. Powers the entire backend.

v18+
🍍

Pinia

Lightweight Vue 3 state management store. Holds the currently selected user session and persists it to localStorage.

v2.1.x
🗺

Vue Router

Client-side routing for SPA. Manages /employee/* and /admin/* route trees with lazy-loaded views.

v4.2.x
📡

Axios

Promise-based HTTP client. All frontend API calls go through a shared Axios instance with base URL /api (proxied to port 5000).

v1.6.x
⚡

Vite

Ultra-fast frontend build tool and dev server. Provides hot module replacement (HMR) and bundles production builds. Runs on port 5173.

v5.x
🔷

Mongoose

MongoDB ODM for Node.js. Defines Schemas, validates data, and provides a clean API for MongoDB queries with populate() for joins.

v8.x
🛠

Development Tools

VS Code (editor), Postman (API testing), Git (version control), MongoDB Compass (DB viewer), Browser DevTools (frontend debug).

Why M-E-V-N?

  • Single Language (JavaScript) — Same language on frontend, backend, and scripts. No context switching between Python/Java/PHP.
  • JSON-Native — MongoDB stores BSON (JSON-like), Vue sends/receives JSON, Express passes JSON — seamless data flow with zero conversion.
  • Open Source & Free — All technologies are free. Ideal for academic projects with no licensing cost.
  • Industry-Relevant — M-E-V-N/M-E-R-N are among the most-used stacks in industry. Demonstrates real-world applicable skills.
  • Non-Blocking I/O — Node.js handles many simultaneous requests without threads, making it highly efficient for API servers.
  • Reactive UI — Vue's reactivity system automatically updates the DOM when data changes — no manual DOM manipulation needed.
