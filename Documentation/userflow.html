8 User Flows

Step-by-step flows for key system interactions.

🆕 Employee — Self Registration
1
Open App

Browse to http://localhost:5173

2
Click "Register" Tab

Switches to registration form

3
Fill Form

Name, email, select department

4
Submit

POST /api/users → status=pending

5
Wait for Approval

Admin must approve before first login

📝 Employee — Apply for Leave
1
Select Account

Pick from dropdown → Continue

2
View Dashboard

See balance cards with progress bars

3
Apply Leave Page

Select type — see remaining balance live

4
Pick Dates

Working days auto-calculated (Mon–Fri)

5
Toggle Paid/Unpaid + Enter Reason

Paid checks balance; unpaid skips check

6
Submit

Backend validates → priority auto-assigned → leave created → status=pending

✅ Admin — Approve User
1
Login as Admin

Select "System Admin" → Continue

2
Dashboard

Sees "Pending Approvals" count

3
Click Approve

PUT /api/users/:id/approve

4
System Initialises Balances

All 5 leave type balances auto-created for the user

5
User Can Now Login

Appears in Select User dropdown

🗂 Admin — Approve/Reject Leave
1
Open Manage Leaves

All requests, sorted High → Medium → Low

2
Filter if Needed

By status, priority, or user

3
Click Approve/Reject

Modal opens for admin comment

4
Submit Decision

PUT /api/leave-requests/:id/status

5
Balance Auto-Updated

If approved + paid → MongoDB $inc atomic update on user's balance
